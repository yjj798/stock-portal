## 六、通道与代理

- 本地代理 `127.0.0.1:7890`（mihomo），可用 `PORTAL_PROXY` 覆盖。
- 每个请求都走「**直连 → 失败再走代理**」双路（`base.get_json(tries_proxy=(False, True))`），不是硬编码单线路。
- 东财 `push2*` / `push2ex` / `emweb` / 新浪：**直连比代理快**，用 `ProxyHandler({})` 强制直连。
- GitHub 系：三条镜像轮询，顺序即新鲜度优先级。
